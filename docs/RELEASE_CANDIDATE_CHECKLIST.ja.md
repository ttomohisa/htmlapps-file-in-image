## 1. 対象環境

- [ ] Windows / Chrome 最新安定版
- [ ] Windows / Edge 最新安定版
- [ ] Windows / Firefox 最新安定版
- [ ] macOS / Safari 最新安定版
- [ ] Android / Chrome 最新安定版
- [ ] iPhone / Safari 最新安定版

## 2. 起動方法

- [ ] `dist/index.html` をHTTP配信で起動
- [ ] `file://` で単一HTMLを直接起動
- [ ] `dist/index.self-extract.html` を起動
- [ ] faviconと左上アプリアイコンが同じ
- [ ] 実行時に不要な外部通信がない

## 3. 埋め込み — 基本

- [ ] PNGをキャリアに選択
- [ ] JPEGをキャリアに選択
- [ ] WebPをキャリアに選択
- [ ] ファイル選択後にドロップ領域がコンパクトになる
- [ ] コンパクト状態でも別ファイルを再ドロップできる
- [ ] 「変更」ボタンで再選択できる
- [ ] 長い日本語ファイル名がレイアウトを壊さない
- [ ] 長い英語ファイル名がレイアウトを壊さない
- [ ] 容量不足が明確に表示される
- [ ] 32 MiB超のpayloadを拒否する

## 4. 圧縮

- [ ] 圧縮しやすいテキストでGZIPが使用される
- [ ] 既に圧縮されたファイル等で、GZIPが大きくなる場合は使わない
- [ ] GZIPありの生成PNGから完全復元できる
- [ ] GZIPなしの生成PNGから完全復元できる

## 5. パスワード保護

- [ ] パスワード保護OFFで埋め込み / 復元
- [ ] パスワード保護ONで埋め込み / 復元
- [ ] 確認用パスワード不一致を拒否
- [ ] 目アイコンでパスワード表示 / 非表示
- [ ] 確認欄の目アイコンも独立して動く
- [ ] 取り出し側の目アイコンが動く
- [ ] 保護OFFで目表示状態が伏字へ戻る
- [ ] 別の埋め込みPNGを選ぶと伏字へ戻る
- [ ] 誤パスワードでAES-GCM認証エラーになる
- [ ] 正しいパスワードで元ファイル名も復元される

## 6. 生成PNGの自動復元確認

- [ ] PNG生成後、確認完了まで保存ボタンが有効にならない
- [ ] 自動復元確認成功後だけ保存できる
- [ ] 保存したPNGを取り出し側で再度復元できる
- [ ] 元ファイルSHA-256が一致する
- [ ] 元ファイル名が一致する
- [ ] MIMEが一致する
- [ ] byte長が一致する

## 7. version互換

- [ ] v0.9.0新規出力のBKFI version 1を復元できる
- [ ] v0.9.0新規出力のBKFC version 1を復元できる
- [ ] 保存済みv0.2.0〜v0.4.0相当のmode 0画像を復元できる
- [ ] 保存済みv0.5.0〜v0.8.0相当のversion 0 / mode 1画像を復元できる
- [ ] 未対応future versionを正常なデータとして誤解釈しない

## 8. 破損 / 変更画像

- [ ] 生成PNGをリサイズしたものは正常に失敗する
- [ ] JPEGへ変換したものは正常に失敗する
- [ ] 画素を変更したPNGは認証 / SHA-256検証で失敗する
- [ ] 普通のPNGを取り出し側へ入れた場合に明確なエラー
- [ ] 壊れた画像ファイルで明確なエラー

## 9. キャンセル / stale result

- [ ] 埋め込みWorker中にキャンセルできる
- [ ] 取り出しWorker中にキャンセルできる
- [ ] キャンセル後に古い結果が表示されない
- [ ] 処理中に別キャリアへ変更しても古い結果が戻らない
- [ ] 処理中に別payloadへ変更しても古い結果が戻らない
- [ ] 処理中にパスワードを変更しても古い結果が保存可能にならない
