# File in Image / 画像にファイルを埋め込む

[English README](README.md)

任意の1ファイルを画像の画素へ埋め込み、生成されたPNGからあとで元のファイルを取り出すブラウザーツールです。処理はブラウザー内で完結します。

> **現在の開発版:** v0.3.0。ここで使用するBKFI/BKFC形式は開発途中の形式で、v1の正式互換形式はまだ固定していません。

## Features

- キャリア画像: PNG / JPEG / WebP
- 埋め込むファイル: 任意の1ファイル、最大32 MiB
- 出力: PNG
- BKFCコンテナ全体をGZIPし、実際に小さくなる場合だけ圧縮結果を採用
- 埋め込み前に元サイズ・実際の埋め込みサイズ・圧縮状態・画像容量・収容可否を表示
- 完全不透明ピクセルのRGB最下位1bitへ決定的に埋め込み
- 復元したファイルをSHA-256で確認
- Drag & Drop / ファイル選択
- 日本語 / 英語UI
- 実行時CDN・API・analytics・telemetry・ファイルアップロードなし
- `file://` 直接起動と単一HTML配布を前提

## 使い方

### 埋め込む

1. キャリア画像を選びます。
2. 埋め込むファイルを選びます。
3. BKFCコンテナを作成し、GZIPで小さくなるか実際に確認します。
4. 表示された「埋め込みデータ」が画像容量に収まることを確認します。
5. 「画像に埋め込む」を実行します。
6. 生成されたPNGを保存します。

### 取り出す

1. 「取り出す」へ切り替えます。
2. このツールで生成したPNGを選びます。
3. GZIP圧縮されたbodyなら自動で展開します。
4. SHA-256が一致したことを確認します。
5. 元ファイルを保存します。

## GZIPについて

圧縮対象はファイル本体だけでなく、ファイル名・MIME・SHA-256・ファイル本体を含むBKFCコンテナ全体です。GZIP後のほうが小さい場合だけ圧縮結果を使用します。

CompressionStreamを利用できないブラウザーでは、埋め込み時は非圧縮で続行します。GZIP済み画像の取り出しにはDecompressionStreamが必要です。

GZIPは容量を減らすための機能で、暗号化ではありません。

## 重要な注意

埋め込みデータは画像画素の最下位bitに保存されます。リサイズ、トリミング、画像編集、JPEG変換、非可逆WebP変換、スクリーンショット、SNSやメッセージアプリによる再圧縮などを行うと、埋め込んだファイルを取り出せなくなる場合があります。生成したPNGはそのまま保持してください。

v0.3.0では、暗号化、高ディテール領域への適応埋め込み、生成PNGの自動復元確認はまだ実装していません。

## Privacy

ユーザーが選んだ画像とファイルはブラウザーのメモリ内で処理します。`connect-src 'none'` を維持し、実行時の外部通信へ依存しません。ファイル内容をlocalStorageやIndexedDBへ保存しません。

## Development

現在の `htmlapps-template` の契約に準拠します。編集対象は `src/index.template.html` で、生成済み `dist` ファイルを直接編集しません。

Windowsでは次を実行します。

```bat
build-standalone.bat
```

## Browser support

現行のChrome / Edge / Firefox / Safari / Android Chrome / iOS Safariを対象とします。`file://` での直接起動も正式要件です。
